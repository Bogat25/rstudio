Put course reference files here: .txt, .md, .R, .Rmd and .csv.
Use one topic per file and descriptive names. Files are read again for every
question; there is no index to update. Up to 12,000 characters are included.
When the files exceed this limit, files sharing words of four or more
characters with the question are included first.

If the open RStudio project has a .ai-context/ directory, that directory is
used instead. Otherwise this user data context/ directory is used. Global
Options can override the context directory. README files are not sent.

The editable system_prompt.txt beside this directory guides the assistant.
The student checks and runs all suggested code themselves.
